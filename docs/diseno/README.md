# Diseño de referencia

- `fuente/`: el HTML de cada pantalla del canvas. Son la fuente de verdad de medidas y estilos. Las imágenes apuntan a `/_blob/…` y no cargan fuera del canvas: las equivalentes están en `public/projects/`.
- `png/`: exportá acá cada pantalla del canvas como PNG, con estos nombres:
  - `inicio-arriba.png`
  - `inicio-proyectos.png`
  - `inicio-herramientas.png`
  - `vinto-pantallas.png`
  - `vinto-decisiones.png`
  - `celular-inicio.png`
  - `celular-vinto.png`

Escritorio: 1440 × 900. Celular: 390 de ancho.
